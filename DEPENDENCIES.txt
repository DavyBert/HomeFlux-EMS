HomeFlux EMS v1.3.1 - dependency policy and audit

Compatibility build
- homey-api: 3.21.2 (the stable npm release checked on 2026-11-09)
- engine.io-client: 3.5.6, selected by homey-api
- socket.io-client: 2.5.0, selected by homey-api
- parseuri: 0.0.6, selected by those clients
- No forced Socket.IO, Engine.IO or parser overrides
- The application version remains 1.3.1; package-lock.json keeps the exact dependency tree.

Compatibility reason
The existing project policy records instability on Homey Pro 2016 when modern
Socket.IO/Engine.IO versions were forced through overrides. This release keeps
the official homey-api dependency chain. That historical hardware observation
was not independently reproduced during this code audit.

Security audit on 2026-11-09
Both the production-only audit and the complete npm audit report four moderate
findings, zero high and zero critical findings. All four are linked to one
underlying parseuri advisory: GHSA-6fx8-h7jm-663j / CVE-2024-36751.
https://github.com/advisories/GHSA-6fx8-h7jm-663j

This upstream finding remains open. The automatic audit proposal downgrades
homey-api and is not a verified compatible repair. parseuri 3.0.2 is an ES module
with a different API; parse-uri 2.0.6 also changes the URL fields expected by the
existing clients. Forcing either parser would risk broken Homey connections.
The audit report in validation/audit-1.3.1 includes the dependency investigation.
